# Tester Message Kit — reusable prompt

## When to use
Any time we're inviting testers to try a build of any product (Fabulously
Me, Nova Health, future apps).

## Prompt to give Claude
"Draft tester invitation messages for [PRODUCT NAME] at [LINK]. Create one
variant per device situation: (1) devices where the build works well —
full invite with link, (2) devices where the build has known issues —
hold the link, send a screenshot, promise the link when fixed, (3) any
in-between devices — link plus honest caveat and orientation/browser tips.
Tone: warm, personal, excited but honest. Always: set expectations about
known rough edges BEFORE they see them, ask for specific feedback
(screenshots of anything odd), and mention what's new since they last saw
it. Never send testers a link to a build that will make a bad first
impression on their device — first impressions with testers only happen
once."

## Device status tracker (update per release)
| Device | Status | Message variant |
|---|---|---|
| Desktop/laptop | ✅ good | Full invite |
| Tablet landscape | ✅ decent | Link + caveat |
| Phone | ❌ characters too small | Hold link, screenshot |

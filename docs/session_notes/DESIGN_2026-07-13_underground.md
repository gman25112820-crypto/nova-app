Underground design session — 13 July 2026 (decisions locked, no code yet)
Identity: The underground is a retreat that gets safer the deeper you go, and a space of the child's own to shape. Depth = ownership = safety. The house rooms are where the world asks gentle questions; the underground asks progressively less — the deepest rooms ask nothing at all.
Descent gradient: Going deeper, rooms get warmer, dimmer, quieter, with fewer on-screen elements and zero prompts/check-ins at depth. Lamplight language throughout. Anti-Finch rule applies architecturally: the space never performs expectation or disappointment.
Structure: A vertical corridor — staircase/tunnel, one room below another. No hub screens, no map. Each room has a "go deeper" doorway; the dig invitation sits at the current deepest point. Chosen because down-is-deeper matches a child's mental model and "safer the deeper" is physically felt.
Starter state: One soft ready-made welcome room. Everything below it is child-created.
Room creation (compose-from-parts, option A): A soft "dig a new room?" doorway — pure invitation, never badged or nudged. Creating = three gentle choices: room feel + name + cosy detail (lamp colour). No unfinished states, no decorating pressure, no caps, no streaks. A half-shaped room is a done room. Freeform decorating is a possible future evolution, not v1.
v1 catalogue: Four room feels (working set: cosy nook, star cave, blanket den, reading burrow) × five lamp colours. Lamp colour implemented as a colour-wash overlay in Flutter (same technique as the shipped mood tint), so art cost = four base images, not twenty. Art via Pollinations (free) with background/quality checks; audit existing orphaned room stills in the repo before generating anything new. fal.ai reserved for hero art later.
Data: Per-child room list (name, feel, lamp colour, order) persisted locally, keyed per child like all existing storage. Needs a Claude Code recon on schema before build — plumbing, not design.
Reserved/flagged: The relationship between the underground retreat and Safe Corner (when a child uses which; whether one points to the other) goes to Helen and Daisy before build. Safe Corner purpose remains theirs.
Build order when we start: house door → house rooms nav confirmed (memory: three-level model) → welcome room → descent corridor → dig flow. One layer at a time, localhost-proven, one commit per logical unit.

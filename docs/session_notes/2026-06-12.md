## Lessons learned

**Hot-reload edits may not persist to file.** Edits made via in-editor hot-reload
or unsaved buffers do not update the source file. Always verify the value on disk
(grep / Read) before building on top of an edit. This caused a false kDebugWaypoints
state at the start of this session.

**Coordinates must be read from the full-scene grid.** sceneFraction values tuned
from a zoomed screenshot drift from reality — the grid overlay (kDebugWaypoints=true)
on the full deployed scene is the only reliable calibration tool.

**Theo / Ollie naming collision fixed.** son_giraffe_1 = Theo, son_giraffe_2 = Ollie.
Comments in fab_world_scene.dart now reflect this.
